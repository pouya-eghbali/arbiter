# Arbiter 0.3.1

A desktop polish update with clearer browser controls and more forgiving
trackpad navigation.

## What’s new

- **A cleaner browser menu:** grouped icon rows, subtle separators, and shortcut
  hints that follow your keyboard settings. A compact strip brings the three
  split-view actions together at the top.
- **Split from the page context menu:** right-click a page to split left/right,
  split top/bottom, or choose another tab to split with. Actions apply to the
  pane you clicked.
- **A clearer focused pane:** the active split-view outline is now 2 pixels
  thick, making the focused view easier to spot.
- **Natural diagonal history swipes:** small vertical movement no longer blocks
  a horizontal Back/Forward gesture at the page boundary. Horizontal content
  scrolling, mostly vertical gestures, and sites that disable overscroll
  navigation still take priority.
- **Stable menu placement:** the browser menu stays above the floating pill as
  its content finishes laying out.
- Updated translations for the new controls in all seven bundled languages.

## Installation

This release contains **desktop downloads only**. No iOS or Android app package
is published. The browser engine, PDF renderer, and credential-storage format
are unchanged from 0.3.0.

Download the package for your desktop from the assets below. macOS downloads
require Apple Silicon and macOS 14.4 or later; the app and DMG are signed and
notarized. Windows downloads are for x64 and are unsigned. Linux downloads are
for x64 and require Ubuntu 24.04 or compatible libraries, the distribution’s
FFmpeg, and a desktop credential store.

Replace the existing application or extracted program folder. Your browser
profile is stored separately. Checksums and corresponding dependency sources
are included with the release assets.
