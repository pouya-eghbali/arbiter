# Arbiter 0.3.2

This release improves Linux compatibility and window behavior, and makes desktop
installation easier.

## Fixes

- Titleless Linux windows now have rounded corners, a soft shadow, and a subtle
  outline. Resizing, maximizing, restoring, and modal overlays preserve the frame
  correctly. Checked on KDE Wayland and XWayland.
- **Ctrl+,** opens Settings on Linux and Windows, including when a web page has
  focus. The shortcut remains customizable.
- Linux builds no longer require the older `libxml2.so.2` ABI.
- Linux packages include the complete matching Qt positioning runtime instead of
  depending on a separately installed distro Qt.

## Easier installation

- **Linux:** native DEB packages for Ubuntu 24.04 / FFmpeg 6 and RPM packages for
  openSUSE Tumbleweed / FFmpeg 8, with a desktop entry and application icon.
- **Windows:** a per-user setup executable with Start menu integration and an
  uninstaller. The portable ZIP remains available. Windows builds are unsigned.
- **Portable Linux:** separate FFmpeg 6 and FFmpeg 8 archives. Run `./install.sh`
  to install for your user, or `./arbiter` to run without installing.

Choose the Linux package matching your distribution and FFmpeg ABI. An FFmpeg 8
archive is named `-ffmpeg8`; the archive without that suffix uses FFmpeg 6.
FFmpeg comes from your distribution, not Arbiter. Never rename or symlink one
FFmpeg major version to another.

## Updating

Close Arbiter before replacing or updating its installation. Browser profiles
and saved credentials are stored separately and are preserved. If switching
from a user-installed Linux archive to a DEB/RPM, uninstall the user copy first
so its menu entry does not override the system installation.

macOS downloads require Apple Silicon and macOS 14.4 or later; the app and DMG
are signed and notarized. Windows downloads are x64. Linux downloads are x64
and require glibc 2.39 or later, the matching FFmpeg runtime, and a desktop keyring.

This is a **desktop-only release**. No iOS or Android packages are published.
Checksums and corresponding dependency sources are included below.
