# Arbiter 0.2.0

Arbiter is now available on Windows, alongside macOS and Linux. This release adds
update checks and quick keyboard help, makes it easier to send feedback, and
fixes Google sign-in compatibility and an interrupted-download crash.

## What's new

- **Windows x64 download:** extract the ZIP and run `bin/arbiter.exe`. This build
  is unsigned; Windows may display an unknown publisher warning.
- **Update checks in About:** see when a newer release is available and open its
  downloads. Automatic checks are enabled by default and can be turned off in
  Settings. You can also check manually.
- **Keyboard shortcut help:** press **Cmd+/** on macOS or **Ctrl+/** on Windows
  and Linux to see common shortcuts. The sheet links to the full, customizable
  shortcut settings, and onboarding introduces the new help shortcut.
- **Feedback from About:** open GitHub forms for bug reports, feature requests,
  and website or extension compatibility problems.

## Fixes and improvements

- Improved compatibility with Google sign-in.
- Fixed a Windows crash when a server ends a download early. Interrupted
  downloads now show an error and can still be retried.
- Fixed Windows page loading failures caused by missing bundled libraries.
- Added scroll-reveal animations and smoother FAQ transitions to the website,
  with reduced-motion preferences respected.

## Download and install

- **[macOS DMG](https://github.com/pouya-eghbali/arbiter/releases/download/v0.2.0/arbiter-0.2.0-macos-arm64.dmg):** Apple Silicon, macOS 14.4 or later. Open the disk image and drag Arbiter to Applications. Signed and notarized. A [ZIP](https://github.com/pouya-eghbali/arbiter/releases/download/v0.2.0/arbiter-0.2.0-macos-arm64.zip) contains the same app.
- **[Windows ZIP](https://github.com/pouya-eghbali/arbiter/releases/download/v0.2.0/arbiter-0.2.0-windows-x86_64-unsigned.zip):** x64, unsigned. Extract the entire archive and run `bin/arbiter.exe`. Windows Hello vault verification requires Windows 11.
- **[Linux archive](https://github.com/pouya-eghbali/arbiter/releases/download/v0.2.0/arbiter-0.2.0-linux-x86_64.tar.xz):** x86_64, Ubuntu 24.04 or compatible with glibc 2.39 or later. Extract the archive and run `./arbiter`. Qt is included; FFmpeg, OpenSSL 3, graphics/audio libraries, and a desktop keyring are supplied by your distribution.

See the [installation guide](https://github.com/pouya-eghbali/arbiter/blob/master/docs/installing.md)
for setup and verification. Existing users can replace the application or
extracted program folder; browser data is stored separately.

## Known limitations

- Saved passwords and local passkeys do not sync between devices yet.
- Some Chrome extensions need APIs Arbiter does not yet support.
- The Windows download is not code-signed.

[Report a problem](https://github.com/pouya-eghbali/arbiter/issues/new/choose)
or [compare changes since 0.1.0](https://github.com/pouya-eghbali/arbiter/compare/v0.1.0...v0.2.0).

## Streaming and DRM

Arbiter does not bundle or download Widevine. When available, it can use a
compatible Widevine module already installed on your device. Widevine is
proprietary Google software governed by applicable Google license terms.
Compatibility with streaming services and playback quality are not guaranteed.
