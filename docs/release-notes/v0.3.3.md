# Arbiter 0.3.3

This desktop update fixes fullscreen video and updates the browser engine’s security patches.

## Fixed

- Videos can enter fullscreen, including from a split view. Leaving fullscreen restores your previous layout.
- Updated Qt WebEngine and Qt PDF together to Qt’s maintenance snapshot with Chromium security backports through **156.0.8078.80**.
- Includes an upstream fix for a missing delegate during view visibility changes.

## Downloads

- **macOS Apple Silicon:** signed and notarized DMG, with a ZIP alternative.
- **Windows x64:** installer or portable ZIP. Windows packages are unsigned; Windows may show a security warning.
- **Ubuntu 24.04 / FFmpeg 6:** DEB or portable archive.
- **Current openSUSE Tumbleweed / FFmpeg 9:** RPM or matching portable archive. FFmpeg 8 packages remain available for systems using that older ABI.

Linux uses your distribution’s FFmpeg libraries. Choose the matching package; restricted codec providers may require a full codec package from your distribution’s supported sources.

Your existing profile, workspaces, passwords, and passkeys are kept when updating. Mobile builds are not part of this release.

## Known limitations

- On macOS, AAC decoding through Web Audio’s `decodeAudioData()` remains unsupported by the codec-free FFmpeg path. Normal HTML media playback uses a separate native decoder path.
- Extension and streaming-service compatibility varies. Arbiter does not bundle or download Widevine.
