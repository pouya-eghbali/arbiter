# Arbiter 0.3.0

A simpler home for passwords, passkeys, and encrypted local-network sync, with
cleaner settings and a redesigned saved-login manager.

## What’s new

- **One credential foundation:** passwords, passkeys, and sync enrollment use
  the same protected credential store. Passkeys use native device verification
  without a separate passphrase setup.
- **Sync that stays enabled:** pair your devices once and encrypted sync keeps
  working while Arbiter is open. Passwords and passkeys sync over your local
  network, including changes and deletions across multiple devices.
- **Fewer macOS Keychain interruptions:** protected Keychain storage replaces
  the old per-credential access path, and background sync does not request
  interactive access to credentials.
- **Better organized settings:** Passwords now contains Passkeys, Sync, and
  Import. Common settings use aligned rows that adapt to the available width.
- **A cleaner saved-login manager:** searchable, scrollable entries with compact
  edit/delete actions and site icons loaded on demand, preferring cached icons.
  Private windows only use cached icons.
- **Refreshed pairing:** a clearer QR layout and pairing links that compatible
  Arbiter mobile source builds can open from the system Camera. Pairing still
  requires device verification and review.
- The website now includes interactive mobile and password-sync previews.

## Existing test profiles

Credential storage has been rebuilt for this release. Passwords, passkeys, and
pairings from earlier test versions are not migrated automatically. Reimport
passwords and pair devices again. For accounts using an older Arbiter passkey,
use another sign-in method to register a new passkey. Existing browsing history,
workspaces, and tabs remain separate from credential storage.

## Installation

This release contains **desktop downloads only**. No iOS or Android app package
is published. The browser engine and PDF renderer are unchanged from 0.2.2.

Download the package for your desktop from the assets below. macOS downloads
require Apple Silicon and macOS 14.4 or later; the app and DMG are signed and
notarized. Windows downloads are for x64 and are unsigned. Linux downloads are
for x64 and require Ubuntu 24.04 or compatible libraries, the distribution’s
FFmpeg, and a desktop credential store.

Replace the existing application or extracted program folder. Your browser
profile is stored separately. Checksums and corresponding dependency sources
are included with the release assets.
