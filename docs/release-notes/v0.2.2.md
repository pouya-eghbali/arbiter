# Arbiter 0.2.2

A small desktop update that makes it easier to choose Arbiter as your default
browser after onboarding.

## What’s new

- **Set your default browser from Settings:** open Settings → Configuration →
  Default browser and choose **Set as default**. Arbiter opens the native system
  confirmation or default-app settings for your operating system.
- The setting shows when Arbiter is already your default browser and refreshes
  when you return from system settings.
- Published an accessible website privacy policy describing local storage,
  optional update checks, and encrypted local-network credential sync.

This release contains desktop downloads only. No iOS or Android release is included.
The browser engine and PDF renderer are unchanged from 0.2.1.

## Installation

Download the package for your desktop from the assets below. macOS downloads are
for Apple Silicon. Windows and Linux downloads are for x64. Replace the existing
application or extracted program folder; your browser profile is stored separately.
The macOS app is signed and notarized. The Windows ZIP is unsigned. Linux requires
Ubuntu 24.04 or compatible system libraries, including the distribution’s FFmpeg
and a desktop credential store.
