# Arbiter 0.2.1

This desktop release adds encrypted local credential sync across multiple
computers, experimental native Liquid Glass on supported Macs, and an updated
browser engine and PDF renderer. We recommend updating from 0.2.0.

## What’s new

- **Encrypted local credential sync:** pair computers from Settings → Sync to
  exchange saved passwords and eligible Arbiter passkeys over your local network.
  Changes and deletions propagate between paired devices; conflicting edits are
  preserved for you to resolve. No Arbiter cloud account or internet relay is used.
- **Experimental Liquid Glass on macOS 26 and later:** native glass for the pill
  and floating browser panels. The existing Glacier appearance remains available
  in Settings. Other operating systems continue to use Glacier.
- Improved native popup dismissal, opening transitions and pill alignment on macOS.

This release contains desktop downloads only. Mobile apps are still in development.

## Security updates

- Updated Qt WebEngine and Qt PDF together to Qt's latest maintained 6.140.0
  security snapshot, including Chromium security backports through 156.0.8078.74.
- Included upstream fixes affecting V8, file-system access and PDF rendering.
- Disabled the affected WebGPU API surface as recommended by the upstream patch.

## Maintenance

- Dependency monitoring now checks Qt's maintained release branch in addition to
  new version tags, so security backports are detected before a new tag appears.
- Repository dependency checks run daily and report network failures explicitly.

## Installation

Download the package for your desktop from the assets below. macOS downloads are
for Apple Silicon. Windows and Linux downloads are for x64. Replace the existing
application or extracted program folder; your browser profile is stored separately.
The Windows ZIP is unsigned. Linux requires Ubuntu 24.04 or compatible system
libraries, including the distribution's FFmpeg and a desktop credential store.
